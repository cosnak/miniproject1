지역별 범죄 통계 및 CCTV 설치 데이터 연계 분석 프로젝트

공공데이터포털의 지역별 범죄 통계 데이터와 CCTV 설치 데이터를 결합하여, 지역별 치안 인프라 현황과 범죄 발생 간의 관계를 분석해봤습니다.

프로젝트 개요
- 분석 주제: 국내 지역별 범죄 발생 현황과 CCTV 설치 데이터 결합 및 통계·머신러닝 분석
- 데이터 출처: 공공데이터포털 (지역별 범죄 통계 데이터, 지역별 CCTV 설치 현황 데이터 등)
- 주요 활용 기술: Python, MariaDB, Web Crawling

진행 단계 (3-Stage Pipeline)

데이터 수집·전처리 및 DB 적재
- 공공데이터포털 원본 데이터 수집 및 결측치·이상치 정제
- 지역 기준 키(Key) 통일을 통한 범죄 통계 및 CCTV 데이터 결합
- Python과 MariaDB연동을 통한 정제 데이터 적재

프로젝트 하기 전 추측
- cctv가 없는 지역에는 범죄가 많이 일어날 것 같다.

목표
- 그래프나 표로 지역별 범죄 통계와 cctv갯수를 한 눈에 볼 수 있게 만들고 싶다.
- 좀 더 많은 정보를 토대로 cctv갯수만 결합하는 것이 아니라, 어느 지역에 어떤 부분에서 범죄가 많이 일어나는지, 외국과 국내의 범죄율 차이가 얼마나 나는지 알아보고 싶다.
